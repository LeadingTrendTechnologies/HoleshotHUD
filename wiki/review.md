# Motos

F8 **Profile → Motos** (horizontal sub-nav under Profile). Local race library and a zoomable Analyze page. Ini key stays `review=`.

- **Record:** off until you **Enable** on the Motos page (`review=0` in the ini). Experimental. The empty page shows Analyze (map beside SPEED / HEIGHT / THR, At this spot, Results), then Enable. Recording off keeps existing motos; delete the last one and the Enable page comes back. **Record** lives on Profile Overview; Motos empty gate still has **Enable**. Hover **Record** explains what recording does (saves race visits to Motos; practice and spectate are skipped). List chips are **All** / **Ranked** / **Saved**. Practice is not recorded (legacy practice rows are purged). Warmup clean laps sit on the race visit as **Warmup L#**, then race **L#**. A clean warmup is that rider’s fastest time and Compare line until a race lap beats it. Spectate / replay is not recorded.
- **Live:** F8 Motos during a moto opens that visit (only while recording is on). New bests and stored lines show on the next paint. Back stays on the list until you open Motos again. Analyze shows a dim **Live** label on the current moto. Compare sits next to Your laps. The map sits beside SPEED / HEIGHT / THR tapes. At this spot sits under them. Results stay below. Compare defaults to **None** (you only). Other riders’ stored lines sit below it, fastest to slowest (cut still compares; crash is skipped). A hitch that jumps ≥30 m does not draw a line across the grass; map dots hold the last recorded sample in that hole. Analyze says **Connection** (same red as Cut) when your line jumped; that is not a cut. At this spot uses `|` between you and them; with None it still shows your speed, gear, throttle, height, and RPM. S1–S3 sit under Your laps (green/red vs Compare when their tape has times). Hover Back / Delete / Save names those icons. The Analyze line covers the whole lap at about 0.6 m spacing up to ~10 km. Zoomed Follow keeps the dirt still on a live moto.
- **Keep:** last 14 days. After 7 days, lines stay for you and session-fastest; everyone else is name / best / finish. Bookmark on the list, or the Analyze bookmark icon, skips auto-delete. Trash on the list (hover **Delete**), or the Analyze trash icon, wipes that moto, including Saved. **Clear** on the list (confirm first) deletes stored motos and leaves Profile; a race being recorded is kept. Analyze Back, Delete, and Save are icons. An eligible race win (P1 with a field; not practice/warmup/solo) shows a gold crown on the list and Analyze; Profile Wins uses the same rule. Analyze dirt stays ~32 m wide when lanes have room. Tight tracks thin only enough that lanes stay separate, so stored lines stay on the dirt. Analyze S/F matches the dirt width. S1–S3 marks sit on the track’s sector gates, same on every lap.
- **Store:** `%LOCALAPPDATA%\Holeshot HUD\reviews\reviews.sqlite`. Each race visit stores the online **server name** when SHM provides it (empty offline). `ranked_servers` is an allowlist of known MXB-Ranked lobby ids (metadata filled when known — Freebies 250 S3- EU/NA/NZ so far). When the server name contains `#lobby_id` in that allowlist, Motos list shows a muted trophy beside the track; Analyze shows it beside the track subtitle; the **Ranked** chip lists only those visits. Recording is the overlay process, not the in-game plugin. A game crash is MX Bikes / the plugin, not Analyze copy. Not attached to Feedback.
- **Profile:** F8 top tab (always). Horizontal sub-nav **Overview** | **Motos**. Overview is name + spider flank cards (Wins / Podium rate / Avg finish left; Crashes per lap / Holeshot rate / Avg Penalty Seconds right; Did not start·Did not finish·Disqualified when present) from eligible race rollups. **All time** / **14 days**. Practice, warmup, and solo are out. Motos list + Analyze live under Profile → Motos (no separate top Motos tab). **Record** toggle lives on Profile Overview; Motos empty gate still has **Enable**. Unsaved Analyze tapes still drop after 14 days; Profile writes compact `profile_races` at visit close. Delete on Motos removes that rollup. **Clear** on Overview wipes the spider only; Motos Clear wipes tapes only. Banner until five all-time races. Hover a spoke for what that trait scores. Rider `state` + `penalty_ms` persist into `profile_races` (OUT = DNF).
- **SHM v16:** game holeshot winner + time. Restart MX Bikes after the plugin update.
