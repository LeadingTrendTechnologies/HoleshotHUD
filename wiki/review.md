# Motos

F8 tab **Motos** (next to Widgets). Local race library and a zoomable Analyze page. Ini key stays `review=`.

- **Record:** off until you **Enable** on the Motos page (`review=0` in the ini). Experimental. The empty page shows Analyze (map beside SPEED / HEIGHT / THR, At this spot, Results), then Enable. Recording off keeps existing motos; delete the last one and the Enable page comes back. The list heading has a **Record** switch. Warmup is not stored; only races. Analyze Race / Warmup only if that visit already has a warmup.
- **Live:** F8 Motos during a moto opens that visit (only while recording is on). New bests and stored lines show on the next paint. Back stays on the list until you open Motos again. Analyze shows a dim **Live** label on the current moto. Compare sits next to Your laps. The map sits beside SPEED / HEIGHT / THR tapes. At this spot sits under them. Results stay below. Compare is each other rider’s stored line (cut still compares; crash is skipped). At this spot uses `|` between you and them. The Analyze line covers the whole lap at about 0.6 m spacing up to ~10 km.
- **Keep:** last 14 days. After 7 days, lines stay for you and session-fastest; everyone else is name / best / finish. Bookmark on the list, or the Analyze bookmark icon, skips auto-delete. Trash on the list (hover **Delete**), or the Analyze trash icon, wipes that moto, including Saved. Analyze Back, Delete, and Save are icons. A race win (P1 with a field) shows a gold crown on the list and Analyze. Analyze S/F matches the dirt width. S1–S3 marks sit on the track’s sector gates, same on every lap.
- **Store:** `%LOCALAPPDATA%\Holeshot HUD\reviews\reviews.sqlite`. Not attached to Feedback.
- **SHM v15:** per-rider Y, speed, RPM, gear, throttle, front brake. Restart MX Bikes after the plugin update.
